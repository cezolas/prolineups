Como usar o treino
  1. Baixe o arquivo e copie para Counter-Strike Global Offensive/game/csgo/cfg/.
  2. No CS2, abra Jogar → Praticar (servidor offline) no mapa.
  3. No console, digite exec lineupspro_dust2.
  4. Digite bind ] lp_next; bind [ lp_prev e use ] e [ para pular de uma lineup para a outra: você vai para o ponto exato do pro, já mirando.
  5. Use só em servidor offline, nunca em partidas online.

Onde você quer a granada?

Escolha o tipo e o lugar onde ela tem que cair: aparecem todas as formas de jogar lá, da mais fácil para a mais difícil. O número é quantas lineups diferentes existem.
