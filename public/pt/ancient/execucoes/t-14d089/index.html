Como dividir no seu time

Cada jogador fica com uma granada. A ordem e o tempo (+Xs) são os que os pros usaram: o +0s abre a execução.

  1. Jogador 1 +0,4s SmokeMédio
    Smoke TR Superior (de Base TR)
    Posição: Base TR · jump throw · parado · clique esquerdo
    sv_cheats 1; setpos -735.942 -2135.969 -131.922; setang -26.7936 64.2515 0
  2. Jogador 2 +1,6s SmokeDifícil
    Smoke Meio (de Base TR)
    Posição: Base TR · jump throw · andando · clique esquerdo
    sv_cheats 1; setpos -735.969 -2135.969 -130.844; setang -27.7535 93.5016 0
  3. Jogador 3 +7,5s MolotovDifícil
    Molotov Bomb B (de Ruínas)
    Posição: Ruínas · correndo · clique esquerdo
    sv_cheats 1; setpos 997.521 -1068.806 4.214; setang -10.8902 50.6641 0

O tempo é contado a partir da primeira granada da execução (mediana das vezes em que os pros jogaram).
