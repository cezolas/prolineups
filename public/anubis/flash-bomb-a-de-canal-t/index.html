Como jogar

  1. Posição: Canal, sempre no mesmo pixel (os pros repetem esta posição com precisão de 5.5 unidades).
  2. Mira: 29.6° para cima, direção (yaw) 60.5°.
  3. Técnica: andando · clique esquerdo.
  4. Onde cai: Bomb A.
Treine num servidor local (console):
